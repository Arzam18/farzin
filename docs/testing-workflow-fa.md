# روال آزمون فرزین: SPRT، رگرسیون و گانتلت

این سند روال اجباری پیش از ادغام هر تغییر در موتور را توضیح می‌دهد. هدف این است
که هیچ تغییری فقط بر اساس «nps بیشتر» یا «به نظر بهتر» وارد نشود و قدرت در آخر
بازی، تاکتیک و موقعیت‌های خاص پس‌رفت نکند.

## ۱. ابزارها

| ابزار | کار |
|---|---|
| `tools/sprt_fastchess.sh` | SPRT پنتانومیال نسخهٔ جدید در برابر نسخهٔ پایه با fastchess (گشایش‌های جفتی، تعویض رنگ) |
| `tools/arena.py` / `tools/sprt.py` | همان کار با پایتون (بدون fastchess) |
| `tools/regression_suite.py` | اجرای موتور(ها) روی مجموعه‌های EPD با `bm`/`am` در بودجهٔ گره یا زمان ثابت |
| `tools/make_tb_suite.py` | ساخت مجموعهٔ آخر بازیِ تأییدشده با جدول Syzygy (فقط یک حرکت برنده) |
| `tools/ccrl/analyze_ccrl_games.py` | آمار بازی‌های CCRL: حریف، رنگ، طول بازی، فاز پایان |
| `tools/ccrl/find_blunders.py` | پیدا کردن اشتباه تعیین‌کننده در هر باخت با موتور مرجع |
| `tools/ccrl/summarize_blunders.py` | خلاصهٔ اشتباه‌ها و ساخت مجموعهٔ رگرسیون `am` |
| `tools/pgn_sprt.py` | وضعیت SPRT پنتانومیال (Elo، بازه، LLR، تصمیم) از روی PGN؛ برای ادغام چند جریان موازی |
| `tools/ccrl/gauntlet.sh` | گانتلت در برابر حریفان CCRL با تنظیمات ثابت (کتاب، seed، داوری) |
| `tools/ccrl/compare_gauntlets.py` | مقایسهٔ جفتی دو گانتلت با گشایش‌های یکسان (اختلاف Elo با بازهٔ ۹۵٪) |
| `tools/ccrl/endgame_starts.py` | استخراج شروع‌های آخر بازی از PGN برای سنجش اثر جدول |

## ۲. SPRT

- **مدل:** آزمون نسبت درست‌نمایی متوالی (GSPRT) با Elo لجستیک و آمار پنتانومیال.
  هر گشایش دو بار با رنگ معکوس بازی می‌شود و واحد مشاهده «جفت بازی» است.
- **کتاب گشایش:** `UHO_Lichess_4852_v1.epd` (گشایش‌های نامتعادل). با گشایش‌های
  نامتعادل تساوی کمتر و حساسیت بیشتر است؛ برای همان دقت، بازی کمتری لازم است.
- **کنترل زمان:** STC برابر `8+0.08` برای تغییرات جست‌وجو/ارزیابی؛ برای مدیریت زمان
  حداقل `10+0.1` (تغییرات زمان در کنترل خیلی کوتاه معنای کمتری دارند).
- **حدود:** `elo0=0, elo1=10` و `alpha=beta=0.05` برای تغییرات مهم؛ برای تغییرات
  کوچک‌تر باید بودجهٔ بیشتری (چند هزار جفت) در نظر گرفت.
- **قاعدهٔ پذیرش:** فقط H1 پذیرفته می‌شود. اگر آزمون به سقف بازی برسد و تصمیم
  نگیرد، تغییر فقط با برچسب «نامطمئن» گزارش می‌شود و پیش‌فرض نمی‌شود.
- **منع توقف زودهنگام:** نتیجهٔ میانی (مثلاً +۲۲ پس از ۱۰۰ جفت) ملاک نیست؛ فقط
  تصمیم SPRT یا نمونهٔ از پیش ثابت‌شده.

```sh
# گزینه‌های پنهان tune_* در نسخهٔ OwnNet فقط با FARZIN_TUNE=1 دیده می‌شوند:
printf '#!/bin/sh\nFARZIN_TUNE=1 exec /path/farzin "$@"\n' > farzin-tune.sh
FASTCHESS=/path/fastchess BOOK=UHO_Lichess_4852_v1.epd TC=8+0.08 \
  NEW_OPTS="option.tune_tm_pct=120" \
  tools/sprt_fastchess.sh tm120 ./farzin-tune.sh ./farzin-base
# شبکهٔ جدید با همان جست‌وجو:
NEW_OPTS="option.EvalFile=/path/fzn2-c1.nnue" tools/sprt_fastchess.sh c1 ./farzin ./farzin
```

## ۳. رگرسیون موقعیتی

پیش از ادغام، نسخهٔ جدید و پایه روی همهٔ مجموعه‌های `tests/regression/` با بودجهٔ
گره برابر اجرا می‌شوند. افت در هر مجموعه باید توضیح داده شود.

| مجموعه | محتوا | معیار حل |
|---|---|---|
| `tb-only-moves.epd` | ۶۰ موقعیت ۴–۵ مهره‌ای که طبق Syzygy **فقط یک** حرکت برنده دارند | انتخاب همان حرکت، **بدون** جدول |
| `tb-hard-only-moves.epd` | ۶۰ موقعیت سخت‌تر: تنها حرکت برنده آرام است (نه کیش، نه ارتقا) و فاصله تا صفرشدن ≥ ۱۲ نیم‌حرکت | همان؛ یک بار بدون جدول (مهارت آخر بازی) و یک بار با جدول (صحت پروب) |
| `ccrl-mistakes.epd` | موقعیت پیش از اشتباه تعیین‌کنندهٔ فرزین ۰٫۵٫۲ در باخت‌های CCRL | پرهیز از حرکتی که در CCRL بازی شد (`am`) |

```sh
python3 tools/regression_suite.py --nodes 1000000 \
  --engine ./farzin-base --engine ./farzin-new tests/regression/*.epd --json reg.json
```

علاوه بر این، تست‌های موجود (`cargo test`: perft، UCI، Syzygy، accumulator) باید
سبز باشند و امضای `bench` برای تغییراتی که نباید جست‌وجو را عوض کنند (مثل
پشتیبانی Syzygy بدون جدول) **دقیقاً برابر** بماند.

## ۴. گانتلت

برای سنجش در برابر موتورهای دیگر از fastchess در حالت `-tournament gauntlet` با
کتاب متعادل `8moves_v3.pgn`، `-srand` ثابت و ترتیب تصادفی استفاده می‌شود. اجرای
نسخهٔ جدید با همان `-srand` همان گشایش‌ها را به همان حریف‌ها می‌دهد، پس دو اجرا
قابل مقایسهٔ جفتی‌اند. بازی‌هایی که با «time forfeit» حریف تمام می‌شوند جداگانه
گزارش می‌شوند.

```sh
BOOK=8moves_v3.pgn tools/ccrl/gauntlet.sh ~/ccrl-work ./farzin-base base base.pgn
BOOK=8moves_v3.pgn tools/ccrl/gauntlet.sh ~/ccrl-work ./farzin-new new new.pgn option.SyzygyPath=/tb
python3 tools/ccrl/compare_gauntlets.py base.pgn base new.pgn new
```
